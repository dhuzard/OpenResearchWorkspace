# Data

Use this folder for scientific data and data references.

- `raw/` — authoritative source data when appropriate to store here. Do not silently edit raw data in place.
- `processed/` — data produced reproducibly from raw or external inputs.
- `external/` — links, manifests, checksums, access notes, or references to data stored elsewhere.

Large, sensitive, regulated, or discipline-specific datasets do not need to live in GitHub. Record their authoritative location and identifiers instead.
