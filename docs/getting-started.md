# Getting started with the GitHub template

The authoritative **non-coding, click-by-click researcher guide** now lives with the GitHub template itself:

## [→ Beginner step-by-step guide](https://github.com/dhuzard/OpenResearchWorkspace-template/blob/main/GETTING_STARTED.md)

Use [`dhuzard/OpenResearchWorkspace-template`](https://github.com/dhuzard/OpenResearchWorkspace-template) when you want to create an ORW research project through GitHub.

The separation is deliberate:

```text
OpenResearchWorkspace
canonical specification + schemas + ORW core
        ↓
OpenResearchWorkspace-template
minimal GitHub adapter + beginner guide
        ↓
researcher's independent workspace
```

Researchers following the GitHub path should not need to install Git, use a terminal, edit YAML, understand branches, or open GitHub Actions.

For non-GitHub creation paths, see the [browser generator](browser-generator.md) or [CLI guide](cli.md).
